# SmPO Dimmed Banner — Style Reference

> An Academic Project Page with its title printed across a darkened gallery of samples.

**Theme:** light

Values come from the static HTML, a few inline styles and the template's `index.css` (Academic Project Page Template, derived from Nerfies) over Bulma 0.9. Bulma's unused palette is excluded. Measurements are normalized; roles are interpreted.

## Overview

SmPO is a near-stock Academic Project Page Template page with one decisive change: the hero is a `.banner` whose background is the paper's sample image under a 50% black gradient, at least 30vh tall, with the title forced white and a soft text shadow. Under the banner the page is plain Nerfies: authors and the "ICML 2025" line at size 5, four dark rounded buttons (Paper, Hugging Face, Code, arXiv), then alternating `hero is-small` sections and one `hero is-light` band for the abstract. Method names in the text ("SmPO-SDXL") are tinted periwinkle `rgb(72,87,220)`. Results are static comparison images separated by `<hr>` rules.

## Components

- **Dimmed image banner.** `section.hero.banner` with `linear-gradient(rgba(0,0,0,0.5), rgba(0,0,0,0.5)), url(banner.png)` centered and covered, white text with `0 1px 3px rgba(0,0,0,0.5)` shadow; contains title, authors and buttons.
- **Dark pill link button.** Bulma `external-link button is-normal is-rounded is-dark`; labels Paper (PDF icon), "🤗 Hugging Face", Code, arXiv.
- **Method name tint.** Inline `<span style="color: rgb(72, 87, 220)">` on the method name in captions.
- **Result strip.** Lazy-loaded full-width comparison image, a sentence above, `<hr>` between strips.

## Do's and Don'ts

- Do put the title on a darkened crop of your best samples, at least 30vh tall.
- Do keep the overlay at 50% black so white text passes contrast on busy images.
- Do tint only the method name in captions.
- Don't leave author links with empty `href=""`, as four authors here do.
- Don't restore the commented-out "Samples generated by Ranni" headings left over from a previous project.

## Quick Start

```css
:root {
  --text: #4a4a4a; --title: #363636; --author: hsl(204, 86%, 53%);
  --method: rgb(72,87,220); --light-band: #f5f5f5;
  --banner-dim: rgba(0,0,0,0.5);
  --font-display: "Google Sans", "Inter", sans-serif;
  --font-body: "Noto Sans", sans-serif;
  --container: 960px;
}
.banner { background: linear-gradient(var(--banner-dim), var(--banner-dim)), url("banner.png") no-repeat center / cover;
  min-height: 30vh; color: #fff; text-shadow: 0 1px 3px rgba(0,0,0,0.5); }
```
