Design prompts from real academic pages

A DESIGN.md gives your coding agent visual rules. Your paper supplies the content. Fill in the brackets and attach the DESIGN.md you picked.

Build a project page

Build a project page for our paper "[title]" ([venue]). Use the attached DESIGN.md for colors, type, spacing and component styling only.
Content comes from our paper: authors and affiliations, [teaser figure or video], abstract, [method figure], [results: tables / videos / comparison slider], BibTeX.
Link buttons: [Paper] [arXiv] [Code] [Data] [Demo].
Keep it a static page that works on GitHub Pages. List which visual decisions came from the reference and which you changed.

Example reference: Efficient Self-Evaluation for Diffusion Language Models via Sequence Regeneration

Build a researcher homepage

Build my academic homepage. Use the attached DESIGN.md for visual rules only.
Content: name, [position, affiliation], photo, short bio, [news], selected publications with [thumbnails / venue badges], [awards], contact links.
Generate the publication list from [publications.bib]. Keep it static and accessible; support dark mode only if the reference does.

Example reference: Aditi Raghunathan

Restyle an existing page

Restyle our existing project page (attached HTML) using the attached DESIGN.md. Keep every piece of content and every link.
Change only colors, fonts, spacing, button and card styling, and section rhythm. Report the before/after tokens you changed.
