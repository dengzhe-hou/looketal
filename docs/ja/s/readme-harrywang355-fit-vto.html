選んだ理由

データセット系リポジトリのすっきりした型を示しています。ラベル付きのティーザー、アブストラクト、データスキーマのフィールドと説明の表、番号付きの生成手順、コメント付きのディレクトリツリーが、一貫した罫線で区切られています。
