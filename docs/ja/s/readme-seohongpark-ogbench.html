選んだ理由

二つのウェイトのワードマーク、統一されたフラットなバッジ、全環境のラベル付きサムネイルグリッドが概要を担います。続いて簡潔な機能リスト、一行の pip install、そしてユーザーがつまずく箇所にぴったり置かれた GitHub Caution コールアウトがあります。
