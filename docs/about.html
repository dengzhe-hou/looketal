About

About Look et al.

A reference library of academic web pages, in the spirit of Refero Styles, for researchers and their coding agents.

What is included

100 paper project pages. Papers accepted at NeurIPS, ICML, ICLR, CVPR and ACL in 2025 and 2026, twenty per venue, ten per year. Candidates come from arXiv comments that state the acceptance and link a project page, taken in arXiv relevance order and kept only if the page loads. Workshop papers are excluded.

29 researcher homepages. Fixed rule: ACM Turing Award laureates (2018–2025) for computing/AI work who keep a personal page, then first and last authors of Best/Outstanding Paper awards at the same five venues in 2024–2025 who keep a personal page. Institutional directory pages, Google Scholar and LinkedIn profiles do not count. Pages that could not be loaded from our network were skipped.

How a DESIGN.md is made

A script reads the page's public HTML and linked CSS and counts colors, font families, sizes, radii and widths. A writer then separates the page's own choices from unused framework defaults (for example Bulma's palette) and writes the DESIGN.md in Refero's structure, adding Page Modules and Provenance sections. Values not measured directly are marked “inferred”. 39 of 129 entries were also checked against the rendered page; each style page says which.

What is not stored

No screenshots. Cards show a synthetic specimen drawn from the measured palette and fonts, and every entry links back to the original page. DESIGN.md files describe visual style; they are not official guides of the authors.

Removal

If you are an author and want your page removed or corrected, open an issue in the project repository and it will be taken down.
