关于 Look et al.

一个学术网页参考库，供研究者和他们使用的编程 agent 参考。

收录了什么

180 个论文项目页，每个会议每年 10 个，覆盖 NeurIPS、ICML、ICLR、CVPR、ACL 的 2025 年和 2026 年，以及 ICCV 2025、ECCV 2026、SIGGRAPH 2025 和 2026、CoRL 2025、CHI 2026、EMNLP 2025，另外还有 10 篇期刊论文，来自 TMLR、TPAMI、JMLR 和 Nature 系列期刊(2025 年和 2026 年)。候选来自 arXiv 的论文备注，备注里要写明已被录用并链接项目页；页面必须能打开，workshop 论文不收。候选共 907 个。大多数会议每年有 40 个以上候选，CHI 2026 只有 19 个，EMNLP 2025 有 37 个。

50 个研究者主页，从 236 位候选中选出，候选按三条固定规则收集。第一条是 ACM 图灵奖得主(2018–2025 年)，以及 NeurIPS、ICML、ICLR、CVPR、ACL 的 Best Paper、Outstanding Paper、Test of Time 奖的第一作者或最后作者(2023–2025 年)。第二条是 ACL Outstanding Paper 的第一作者和最后作者(2023–2025 年)。第三条来自认知科学和计算神经科学，包括鲁梅尔哈特奖得主(2010–2025 年)、格鲁什科博士论文奖得主(2018–2025 年)、CogSci 计算建模奖的作者(2020–2025 年)和 CCN 大会主旨报告人(2023–2025 年)。只收个人主页，机构的人员名录页、Google Scholar 和 LinkedIn 不算。

40 个代码 README，分四组各 10 个，分别是视觉(CVPR、ICCV、ECCV)、机器学习(NeurIPS、ICML、ICLR 和期刊)、语言(ACL、EMNLP)，以及图形学、机器人和人机交互(SIGGRAPH、CoRL、CHI)。候选是上面这些项目页链接的官方代码仓库：907 个页面里有 744 个链接了仓库，其中 647 个仓库的 README 不少于 2.5 KB。README 直接用 GitHub API 返回的 HTML 渲染，采用 GitHub 浅色主题和仓库页面的 920px 宽度，再按和下文页面相同的方法评审，标准是头部、图片、结构和完成度。GitHub 固定了字体和颜色，所以 README 的 DESIGN.md 记录的是结构和呈现方式(头部区块、徽章、章节结构、组件)，而不是 CSS。

怎么选的

只看视觉设计，分两轮选。每个候选都按 1440×900 截图。第一轮由模型评审看完一组候选的首屏，留下 20 个；第二轮看每个页面高 2700px 的长截图，选出 10 个。第一批研究者候选作为一整组评审，先留 60 个，再选 30 个。标准是字体排印、超出模板默认值的独特面貌、布局和节奏、研究成果的展示方式，以及完成度。研究内容、会议和知名度都不考虑；两个页面不相上下时，优先选能带来新风格的那个。只截到加载动画、空白页或反爬页面的候选无法评判，直接去掉。每个页面的入选理由写在它的风格页上。

DESIGN.md 怎么写

先看实际渲染出来的页面。用无头浏览器读取标题、各级标题、正文、按钮和容器的计算样式，实际加载的字体，首屏结构(按 DOM 顺序)，以及首屏各颜色所占比例。然后再从页面的样式表和标记里补充选择器、悬停和响应式规则。CSS 和渲染结果不一致时，以渲染结果为准。每个文件都按固定的章节顺序写(Overview、First Viewport、配色/字体/间距 token、Layout Metrics、Components、Page Modules、套用到其他内容时的建议、给 agent 的提示词指南和 Quick Start)，并自动检查提示词里用到的每个颜色是否都在 token 表里。270 条里有 270 条对照过实际渲染的页面。DESIGN.md 只写英文版，这样所有读者和编程 agent 用的都是同一份文本。

方法在一次还原测试之后做过修订。只拿到 DESIGN.md 和另一份内容的制作者重做了 5 个页面，一个不知道原页面的评判者把重做的页面和原页面配对，再由分析者对照线上页面按 1 到 5 分打相似度。用只根据 CSS 写的第一版时，评判者 5 个全部配对正确，但相似度平均只有 3.0(2 到 4)，主要原因是 CSS 里写了、页面上却没有显示的值。用现在的版本，在同样 5 个页面上做同样的测试，仍然全部配对正确，相似度平均 4.0(5 个都是 4 分)。另外抽查了 10 个文件，约 129 处说明里有 4 处数值写错，已经改正。

截图

每条都展示原页面首屏的截图，缩小到 1200×750，注明版权归作者所有，并链接回原页面。和其他设计参考网站一样，截图只用于参考和比较。DESIGN.md 描述的是视觉风格，不是作者发布的官方指南。
