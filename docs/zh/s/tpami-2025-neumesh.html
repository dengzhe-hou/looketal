入选理由

带纹理的定制字标让标准的 Nerfies 风格底子一眼就有辨识度，另有带说明的加框 GUI 预览图和整齐的胶囊按钮。相比相似的 ViewCrafter 和 MOWA 页面，它的标志性元素更强，因此入选。

下面的说明和 DESIGN.md 正文是英文。为了让编程 agent 读同一个版本，这部分没有翻译。
